# ◈ Artifact Archives

**Status:** OFF by default.  
**Admin surface:** Upcoming Features → More Systems.  
**Public page:** `/artifact-archives/`  

Collect, level, socket and salvage artifacts with custom stats, set bonuses and acquisition rules.

## Configuration model


### Blueprint 1: Void Protocol

This blueprint demonstrates a customizable artifact archives setup. Use the structured editor to change names, schedules, requirements, costs, rewards, effects, prerequisites and metadata without editing JSON. It is safe to leave the definition disabled while balancing values. 

**Design notes**
- Start disabled and enable the site section only after QA.
- Prefer explicit numeric weights over hidden hard-coded probabilities.
- Keep permanent and temporary content separate so event content can expire cleanly.
- Give every reward a stable identifier when it needs analytics or audit history.
- Use the page as a player-facing view; use Upcoming Features as the source of truth.
