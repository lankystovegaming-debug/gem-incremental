# Photoreal reference notes

The photoreal atlas is locally generated artwork used as a visual reference and
game asset source. Real-world mineral forms were cross-checked against Wikimedia
Commons mineral specimen references during implementation.

Reference examples consulted:
- Quartz specimen forms: Wikimedia Commons quartz specimen pages.
- Calcite specimen: Wikimedia Commons `Calcite-20188.jpg`.
- Feldspar specimen: Wikimedia Commons `Feldspar 1659.jpg` (public-domain release).
- Fluorite specimens: Wikimedia Commons fluorite specimen pages.
- Hematite specimen: Wikimedia Commons `Hematite-254990.jpg`.
- Obsidian specimen: Wikimedia Commons Obsidian category/specimen pages.
- Agate specimen: Wikimedia Commons agate specimen pages.
- Jasper specimen: Wikimedia Commons `Jasper.pebble.600pix.bkg.jpg` (public-domain release).

The runtime does not hotlink these sources; the game uses local generated assets.
