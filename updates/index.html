What's new

Update Log

New features, improvements, balance changes, and bug fixes.

Latest v0.6.0 17 August 2026

Gem Mutations

New

  • Rolled gems now have a small chance to receive a permanent mutation.
  • Added Polished, Gilded, Prismatic, Celestial, and Corrupted mutations.
  • Mutations increase a gem's monetary value without changing its rarity or weight.
  • Mutation names and value multipliers appear on roll results and inventory cards.
  • Added a Mutation Index that permanently records discoveries and personal records.

Balance

  • Reduced Legendary gem values by 15%.
  • Reduced Mythic gem values by 25%, with Painite set to a $6,000 base value to preserve progression.
  • Reduced Exotic and Cosmic gem values by 20%, excluding Lanky Gem.
16 August 2026

Potions & progression improvements

New

  • Added the one-roll Legendary Potion and Mythic Potion.
  • Legendary Potions require 500 lifetime rolls to use.
  • Mythic Potions require 2,500 lifetime rolls to use.
  • Potions can still be crafted and collected before reaching their use requirement.

Improvements

  • Roll results now record the full effective Luck used, including potion and event boosts.
  • The Stats page now displays timed, one-roll, and Admin Event Luck correctly.
  • Luck no longer rolls gems whose rarity denominator is lower than the active Luck value.
16 August 2026

Community & Admin tools

New

  • Added redeemable codes that can award money and potions.
  • Added owner-controlled, limited-time Admin Events.
  • Admin Events now support both additive bonuses and multiplicative modifiers.
  • Added improved loot-box rewards, including potion rewards.

Security & fixes

  • Added protection against gaining extra rolls by running the game in multiple tabs.
  • Improved server-side validation for rewards, potion use, and Admin actions.
v0.5.0 15 August 2026

Expanded equipment progression

New

  • Added Tier 6–8 Boots and Bags with new late-game crafting recipes.
  • Added Tier 9 and Tier 10 Pickaxes with lifetime-roll requirements.
  • Expanded the gem collection with new rare materials and hidden discoveries.
  • Added infinite storage upgrades with gradually increasing prices.

Quality of life

  • The Bottomless Bag recipe now identifies which gems are still missing.
  • Inventory equipment can now be unequipped and re-equipped normally.
  • Stored gems show the roll number and Luck used when they were discovered.
